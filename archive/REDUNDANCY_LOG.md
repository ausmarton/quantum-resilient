## Redundancy Check Process

Before making changes:
1. Read existing content in target section
2. Check if similar content exists elsewhere
3. If duplication found:
   - If in Chapters 3-4: Fix it
   - If outside Chapters 3-4: Log it here, don't fix

After making changes:
1. Review new content for redundancy with existing content
2. Check if new content duplicates something already said
3. Consolidate or remove redundant statements

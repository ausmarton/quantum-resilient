# Output Directory Structure

This document explains where experiment results and analysis outputs are stored.

## Main Output Locations

### 1. Individual Experiment Results
**Location**: `results/<environment>/<scenario-id>/`

Each individual experiment creates:
```
results/native/rsa2048-smoketest-p256-r50/
├── raw/
│   └── run.jsonl              # Raw telemetry events
├── merged/
│   ├── merged.jsonl           # Sorted merged events
│   └── merged.parquet         # Parquet format (if generated)
├── stats/
│   └── summary.json           # Statistical summary (p50, p95, p99, throughput)
├── figures/                    # ⚠️ Individual experiment plots (may be redundant)
│   ├── latency_cdf.png
│   └── throughput.png
└── manifest.json              # Run metadata
```

**Note**: The `figures/` subdirectory in individual experiments is generated by the experiment runner scripts (`run_local.sh`, `run_minikube.sh`) and may be redundant if you only need the combined figures from `final-results/`.

### 2. Final Combined Results (Dissertation-Ready)
**Location**: `final-results/` (or `final-results-smoke/` for smoke tests)

This is the **main output** for dissertation work, generated by `run_all_experiments.sh`:

```
final-results-smoke/
├── index.json                  # Master experiment index (all experiments)
├── aggregated_stats.json       # Statistics aggregated across all experiments
├── aggregated_stats.csv        # CSV version (if generated)
├── hypothesis_tests.json      # Statistical hypothesis test results
├── hypothesis_table.csv        # CSV version of hypothesis tests
├── hypothesis_interpretation.txt  # Human-readable interpretation
├── report.pdf                  # Dissertation-ready PDF report
├── figures/                    # ✅ Combined figures (use these!)
│   ├── combined_ecdf.png       # ECDF across all algorithms/environments
│   ├── classical_vs_pqc.png    # PQC vs classical comparison
│   ├── scaling_curves.png      # Throughput/latency scaling
│   ├── ecdf_by_payload.png     # ECDF by payload size
│   ├── ecdf_*.png              # Per-algorithm ECDFs
│   └── scaling/                # Replica scaling plots (if applicable)
├── stats/                      # Additional statistics
│   ├── aggregated_stats.json
│   ├── effect_sizes.json
│   └── environment_deltas.json
└── tables/                     # CSV tables for dissertation
```

**This is where you should look for dissertation-ready outputs!**

### 3. Analysis Notebooks Output
**Location**: `analysis/figures/dissertation/`

This folder is used by Jupyter notebooks (`analysis/notebooks/99_generate_figures.ipynb`) for manual figure generation. It's **separate** from the automated `run_all_experiments.sh` workflow.

If you run the notebooks manually, figures will appear here. Otherwise, use `final-results/figures/` instead.

## Directory Cleanup Recommendations

### Redundant Directories (Safe to Remove)

1. **Individual experiment figures** (if you only need combined figures):
   ```bash
   # Remove figures from individual experiments
   find results/native -type d -name "figures" -exec rm -rf {} +
   find results/minikube -type d -name "figures" -exec rm -rf {} +
   ```

2. **Old experiment results** (if no longer needed):
   ```bash
   # Remove old experiments (be careful!)
   rm -rf results/exp1
   rm -rf results/k8s_exp1
   ```

### Required Directories (Keep These)

- `final-results/` or `final-results-smoke/` - **Main output for dissertation**
- `results/<env>/<scenario-id>/merged/` - Raw data (needed for re-analysis)
- `results/<env>/<scenario-id>/stats/` - Individual experiment stats
- `generated-scenarios/` - Scenario definitions

## Workflow Summary

1. **Run experiments**: `./run_all_experiments.sh --smoke-test --envs native,minikube`
2. **Check results**: Look in `final-results-smoke/` (or `final-results/`)
3. **Use figures**: Copy from `final-results-smoke/figures/` to your dissertation
4. **Use tables**: Copy from `final-results-smoke/tables/` (if generated)
5. **Use stats**: Reference `final-results-smoke/aggregated_stats.json`

## Verification

Run the verification script to check what was generated:
```bash
./scripts/verify_experiments.sh
```

This will show:
- Which experiments succeeded/failed
- What analysis outputs exist
- What figures were generated
- Any missing files
